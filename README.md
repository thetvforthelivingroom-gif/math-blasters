# Math Blasters

A fun, browser-based math tower defense game.

## MVP goals

- Playable in a desktop browser
- No backend required
- Addition and subtraction questions
- Correct answers trigger attacks against incoming enemies
- Score, base health, victory, and defeat states
- Responsive interface suitable for future mobile support
- Deployable to GitHub Pages

## Development principles

- Keep the first version small and playable.
- Use HTML, CSS, and vanilla JavaScript unless a dependency is justified.
- Test the actual game in a browser.
- Do not claim a test passed without evidence.
